# Magnetic descriptors report

`magnetic_descriptors.md` is the report on `m1_spin`, `sigma_r2_spin`, `f_bond_spin`,
`mu_site_std`, `spin_frustration` and `spin_charge_correlation`. It covers their
definitions, formulas, implementation, physical meaning, analytic behaviour, where the
magnetization sits relative to the PAW spheres, numerical robustness and a survey over the
1,679 magnetic structures of the 6,059-structure VASP dataset.

- `figures/`: 11 figures, PNG (200 dpi) and PDF (vector).
- `data/`: every table behind the figures and numbers.
- `scripts/`: the scripts that regenerate them. The order and inputs are in section 12 of
  the report.
