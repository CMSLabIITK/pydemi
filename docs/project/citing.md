# Citing pydemi

If you use pydemi, please cite the software (Zenodo) and, once it is published, the paper that
describes it.

**Software.** S. K. Maurya, *pydemi: interpretable, fixed-length descriptors from a VASP
CHGCAR*, version {{ version }}, Zenodo,
[doi:10.5281/zenodo.24415538](https://doi.org/10.5281/zenodo.24415538).

@software{pydemi,
  author    = {Maurya, Shubham Kumar},

## Please also cite

- **ChargE3Net**, if you use predicted densities: T. Koker, K. Quigley, E. Taw, K. Tibbetts
  and L. Li, Higher-order equivariant neural networks for charge density prediction in
  materials, *npj Comput. Mater.* **10**, 161 (2024),
  [doi:10.1038/s41524-024-01343-1](https://doi.org/10.1038/s41524-024-01343-1).
- **The dataset of the property models**, if you use the estimates: Kumar et al.,
  *J. Chem. Inf. Model.* **66**, 7113 (2026),
  [doi:10.1021/acs.jcim.6c00235](https://doi.org/10.1021/acs.jcim.6c00235), and the
  Materials Project: A. Jain et al., *APL Mater.* **1**, 011002 (2013).
- **The covalent radii** behind the regions: B. Cordero et al., *Dalton Trans.* 2832 (2008).
